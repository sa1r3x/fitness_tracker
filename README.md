# 🏋️‍♂️ Фитнес-Трекер на Python

Telegram-бот для ведения спортивного дневника прямо во время тренировки. Проект разработан на базе современного асинхронного фреймворка **aiogram 3.x** и использует **SQLite** для надежного хранения данных.

---

## 🔥 Ключевые архитектурные фичи

- **Агрегированный дневник по дням:** Бот не засоряет базу данных отдельными строчками. Он аккуратно группирует все подходы под каждым упражнением и сохраняет всю тренировку целиком за конкретную дату.
- **Умный FSM-сценарий (Конечные автоматы):** Реализован режим активной тренировки (`workout_active`). Пользователю больше не нужно вручную вводить номер подхода — система автоматически рассчитывает его на основе истории текущей сессии.
- **Броня от багов (Валидация данных):** 
  - Встроенная проверка веса и повторений через `.isdigit()`. Бот вежливо заблокирует текстовый спам или случайные опечатки.
  - Автоматическое приведение регистра упражнений к стандарту через `.capitalize()` (для бота `жим лежа`, `Жим Лежа` и `ЖИМ ЛЕЖА` — это одно и то же упражнение).
- **Защита от сброса меню:** Кастомная эхо-ловушка жестко удерживает клавиатуру тренировки активной, даже если пользователь случайно отправит в чат текстовый бред.
- **Инструменты контроля сессии:** Возможность посмотреть текущую тренировку в один клик или стереть последний косячный подход через кнопку `↩️ Удалить подход`.

---

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Фреймворк:** [aiogram 3.x](https://github.com) (Asyncio)
- **База данных:** SQLite (библиотека `sqlite3`)
- **Управление окружением:** `python-dotenv` (для защиты токенов)

---

## 💻 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd fitness_tracker
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корневой папке и добавьте ваш токен бота:
   ```env
   BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwXyZ
   ```

4. Запустите бота:
   ```bash
   python main.py
   ```
